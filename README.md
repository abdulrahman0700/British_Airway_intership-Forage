# British Airways Virtual Internship — Forage

This repository contains my work from the **British Airways Data Science Virtual Internship** on [Forage](https://www.theforage.com/). The internship is split into two tasks, each delivered as a Jupyter notebook.

## 📁 Contents

| File | Description |
|---|---|
| `British_Airways_Project_1_Finish.ipynb` | Task 1 — Web scraping customer reviews, cleaning the text, and extracting insights |
| `British_Airways_Project_2_Finish.ipynb` | Task 2 — Building a machine learning model to predict customer buying (booking) behaviour |

## ✈️ Project Overview

### Task 1: Scraping and Analysing Customer Reviews
- Scraped British Airways customer reviews from [Skytrax](https://www.airlinequality.com/) using web scraping techniques.
- Cleaned and pre-processed the raw text data (removing noise, punctuation, stop words, etc.).
- Performed exploratory analysis and sentiment/topic analysis to uncover key themes in customer feedback.
- Visualized findings (e.g., word clouds, sentiment distribution) to summarize what customers value and complain about most.

### Task 2: Predicting Customer Buying Behaviour
- Used a customer booking dataset to explore factors that influence whether a customer completes a booking.
- Performed data cleaning and feature engineering to prepare the dataset for modeling.
- Trained and evaluated a machine learning model (e.g., Random Forest) to predict booking completion.
- Analyzed feature importance to identify the strongest predictors of customer purchasing decisions.
- Summarized results and business recommendations based on the model's findings.

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abdulrahman0700/British_Airway_intership-Forage.git
   cd British_Airway_intership-Forage
   ```
2. Install the required dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn beautifulsoup4 requests nltk
   ```
3. Launch Jupyter Notebook and open either file:
   ```bash
   jupyter notebook
   ```
